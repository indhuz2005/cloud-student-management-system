# \# Cloud-Based Student Management System

# 

# \## Project Overview

# 

# The Cloud-Based Student Management System is a web-based application developed using Python and Flask. It provides a centralized platform for managing student information, courses, and academic records.

# 

# \## Technologies Used

# 

# \- Python

# \- Flask

# \- SQLite

# \- HTML

# \- Jinja2

# 

# \## Features

# 

# \- User login

# \- Add, view, and delete student records

# \- Add and view course records

# \- Add, view, and delete academic records

# \- Dashboard displaying student and course counts

# \- SQLite database integration

#

# \## Installation and Setup

# 

# 1\. Clone or download this repository.

# 2\. Install the required packages:

# 

# &#x20;  `pip install -r requirements.txt`

# 

# 3\. Run the application:

# 

# &#x20;  `python app.py`

# 

# 4\. Open the local URL displayed in the terminal in your web browser.

#
